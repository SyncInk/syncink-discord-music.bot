Complete Command Reference

Slash / Prefix Category Parameters Description
/play?play, ?p Playback query Search and stream tracks from YouTube, Spotify links, or SoundCloud.
/search?search Playback query Opens an interactive multi-result picker to choose the exact version.
/pause?pause Playback — Pauses active voice playback while preserving timeline state.
/resume?resume Playback — Resumes paused playback seamlessly from where you left off.
/skip?skip, ?s, ?next Playback count (optional) Skips the current track (or multiple queued tracks forward).
/previous?previous, ?prev Playback — Replays the previous track from your current session history.
/replay?replay Playback — Restarts the current track from the beginning.
/volume?volume, ?vol Playback percent (1–200) Displays or adjusts server playback gain volume.
/stop?stop Playback — Stops playback, disables active AutoPlay/radio, and clears the queue.
/leave?leave, ?dc Playback — Disconnects the bot cleanly from the active voice channel.
/radio?radio Radio country (optional) Browse interactive worldwide radio countries or tune directly by country.
/lofi?lofi Radio — Starts 24/7 study and chill lofi radio playback immediately.
/247?247, ?alwayson Radio mode (on/off) Keeps the bot connected in your voice channel 24/7 without inactivity timeout.
/queue?queue, ?q Queue action (optional) Displays upcoming tracks interactively or clears the queue (`clear`).
/remove?remove, ?rm Queue position Removes a specific track at the given upcoming queue index.
/shuffle?shuffle Queue — Randomizes upcoming queued tracks.
/loop?loop, ?repeat Queue off / track / queue Cycles or sets repeat mode across track or queue.
/np?np, ?nowplaying Queue — Displays the current live progress bar card for the active track.
/audia?audia Audia AI — Opens Audia AI Control Center to set mood/language/style and Block or Unblock artists.
/autoplay?autoplay Audia AI mode (on/off) Enables or disables continuous AI track recommendations after queue end.
/spotify connect Spotify — Generates a secure Spotify OAuth PKCE link to connect your library.
/spotify add Spotify url Saves a public Spotify playlist link into your synced library.
/spotify status Spotify — Shows your linked Spotify account status and synced playlists.
/spotify disconnect Spotify — Removes saved Spotify OAuth tokens cleanly from the database.
/help?help Utility — Displays the categorized interactive help menu in Discord.
/invite?invite Utility — Provides the official invite link to add SyncInk Radio to another guild.
